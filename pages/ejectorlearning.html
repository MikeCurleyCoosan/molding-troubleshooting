Ejector Stroke learning

If alarm "2024:10503: Ejector 1: Function cannot be executed: Stroke Learning required" appears on the Nestal IMM, please carry out the following steps.

1. Select setup mode by turning key to 3 o clock position & pressing setup button(triangle & hand on button).

2. Using the jump function (the arrow key just to the left of the mouse), press arrow key then press C184.1 - this will bring you to page 1.4.(Mould change)

3. Set C184.1(Ejector 1 stroke learning) from 0 to 1.

5. Press and keep holding the Ejector forward button, then press the Green start cycle button

6. Clamping/Ejector and Injection Unit will move forward & back for a couple of cycles. When injection unit teaching is completed C184.1 will go back to 0.

7. Turn Cycle start mode by turning the key back to the 12 o clock position.

8. Put the IMM back into Auto mode

9. If the stroke check button is illuminated press the stroke check status button to clear. The IMM in now ready to be started

You can also access page 1.4 by clicking on topic menu - select mold movement the click on page - select 1.4 mold change - C184.1 will be available from here.

Or using short cut key S - keep pressing this button until page 1.4 comes up.

This procedure can also be accessed from the molding machine HMI,

From the overview screen click on function menu - select manual,

Then click on User manual - select setting/setup work - then select setting up mold.

Go to the bottom of this page & follow instruction for learning ejector unit stroke.
